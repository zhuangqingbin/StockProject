# Artisan Espresso Club - Login Page

A premium, conversion-optimized login page for a $200/month espresso membership service targeting Bay Area tech professionals.

## Design Highlights

- **Target Audience**: Mid-career Bay Area tech professionals with disposable income and a passion for coffee
- **Conversion Focus**: 6-month commitment with clear value proposition and social proof
- **Aesthetic**: Dark, sophisticated UI with warm espresso-toned accents
- **Typography**: Playfair Display (serif) for headings, DM Sans for body text

## Features

- Responsive design (mobile-first)
- OAuth login options (Google, Apple)
- Password visibility toggle
- 6-month plan upsell with toggle
- Social proof elements (member count, rating, testimonial)
- Toast notifications for user feedback
- Accessible keyboard navigation
- Subtle ambient animations

## Usage

Simply open `index.html` in a web browser. No build step required.

```bash
# macOS
open index.html

# Or start a local server
python -m http.server 8000
```

## Conversion Optimization

1. **6-month commitment highlighted** as "Recommended" with savings callout
2. **Social proof** with member count, rating, and testimonial
3. **Premium equipment** (La Marzocco, Decent DE1) mentioned to justify price
4. **Trust signals** throughout (encryption badge, security messaging)
5. **Low friction** with OAuth options and clear CTA
6. **Upsell integrated** into login flow (6-month toggle)
