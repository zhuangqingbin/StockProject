数据库 Schema (新增表)

MySQL 新增 4 张表
📋 strategies — 策略定义
字段类型说明
idINT PK AUTO主键
nameVARCHAR(100)策略名称
descriptionTEXT策略描述
source_typeENUM'template' | 'custom'
template_idVARCHAR(50)模板标识 (如 ma_crossover)
codeTEXT策略 Python 代码
default_paramsJSON默认参数 {"fast": 5, "slow": 20}
required_feedsJSON所需数据源 ["daily_kline", "moneyflow"]
authorVARCHAR(50)作者
created_at / updated_atDATETIME时间戳
🚀 backtest_runs — 回测运行记录
字段类型说明
idINT PK AUTO主键
strategy_idINT FK关联策略
paramsJSON本次参数覆盖
symbolsJSON标的列表 ["000001.SZ", ...]
start_date / end_dateDATE回测区间
initial_cashDECIMAL初始资金
commission_rateDECIMAL手续费率
benchmarkVARCHAR(20)基准指数代码
data_feedsJSON使用的数据源
statusENUM'pending'|'running'|'completed'|'failed'
progressSMALLINT进度 0-100
error_messageTEXT失败原因
metricsJSON绩效指标汇总 (年化/回撤/夏普...)
submitted_byVARCHAR(50)提交人
created_at / finished_atDATETIME提交/完成时间
💰 backtest_trades — 交易明细
字段类型说明
idINT PK AUTO主键
run_idINT FK关联回测记录
trade_dateDATE交易日期
symbolVARCHAR(20)标的代码
directionENUM'buy' | 'sell'
priceDECIMAL成交价格
sizeINT成交数量
commissionDECIMAL手续费
pnlDECIMAL本笔盈亏 (卖出时计算)
📈 backtest_daily — 每日净值快照
字段类型说明
idINT PK AUTO主键
run_idINT FK关联回测记录
trade_dateDATE交易日
portfolio_valueDECIMAL组合总价值
cashDECIMAL现金余额
daily_returnDECIMAL当日收益率
cumulative_returnDECIMAL累计收益率
drawdownDECIMAL当前回撤
positionsJSON持仓快照 {"000001.SZ": {size, value}}

数据源注册表 (插件式)

每个数据源注册为一个 DataFeedPlugin，提供统一接口：
class DataFeedPlugin(ABC):
  name: str            # "daily_kline"
  table: str           # MySQL 表名
  columns: list        # 可用列
  def query(symbol, start, end) → DataFrame
  def to_bt_feed(df) → bt.feeds.PandasData
新增数据源只需: ① 实现 DataFeedPlugin ② 在 data_registry.py 中注册 → 前端自动出现在数据源选择列表
