API 路由表

Market 模块
GET /api/market/overview — 仪表盘全量数据 (预计算)
GET /api/market/indices — 5大指数行情
GET /api/market/distribution?date= — 涨跌分布直方图
GET /api/market/ranking?type=pct_chg&order=desc&limit=20 — 排行榜 (涨幅/跌幅/成交/换手)
GET /api/market/limit-stats?date= — 涨停分析 (涨停数/跌停/炸板/连板)
GET /api/market/limit-stocks?type=up&date= — 涨停/跌停股列表
Industry 模块
GET /api/industry/heatmap?date= — 板块热力图数据 (Treemap)
GET /api/industry/{name}/detail — 行业详情 (指数走势+统计)
GET /api/industry/{name}/stocks?sort=pct_chg&order=desc — 行业内个股排行
Stock 模块
GET /api/stock/{code}/profile — 基本信息 + 今日行情 + 估值
GET /api/stock/{code}/kline?period=daily&start=&end= — K线数据 (日/周/月)
GET /api/stock/{code}/valuation-history?start=&end= — PE/PB/PS 历史时序
GET /api/stock/{code}/peers — 同板块个股排名
GET /api/stock/{code}/history?start=&end=&page=&size= — 历史行情表格 (分页)
GET /api/stock/search?q= — 模糊搜索 (代码/名称)
Flow 模块
GET /api/flow/north?days=30 — 北向资金趋势 (沪/深/合计)
GET /api/flow/stock/{code}?days=30 — 个股资金流 (超大/大/中/小单)
GET /api/flow/stock/{code}/detail?date= — 某日大单明细
TopList 模块
GET /api/toplist/daily?date= — 今日龙虎榜列表
GET /api/toplist/stock/{code} — 个股历史上榜记录
Screener 模块
GET /api/screener/filters — 可用筛选条件列表 (字段/类型/范围)
POST /api/screener/query — 执行筛选 (body: conditions[], sort, page)
GET /api/screener/export?format=csv — 导出筛选结果

筛选器可用条件

行情维度
· 涨跌幅 (pct_chg)
· 现价 (close)
· 成交额 (amount)
· 成交量 (vol)
· 换手率 (turnover_rate)
· 振幅 (high-low)/close
· 连涨/连跌天数
估值维度
· PE(TTM) (pe_ttm)
· PB (pb)
· PS(TTM) (ps_ttm)
· 总市值 (total_mv)
· 流通市值 (circ_mv)
· 总股本 (total_share)
· 流通股本 (float_share)
资金+分类维度
· 主力净流入 (net_mf_amount)
· 超大单净流入
· 大单净流入
· 行业 (industry)
· 市场 (exchange)
· 是否 ST
