# 环境变量

## 共享 MySQL 变量

- `MYSQL_USER`
- `MYSQL_PASSWORD`
- `MYSQL_HOST`
- `MYSQL_PORT`
- `MYSQL_CHARSET`

## Data Hub 变量

- `TUSHARE_TOKEN`
- `TS_MYSQL_DATABASE`
- `AK_MYSQL_DATABASE`

## Quant Platform 变量

- `QV_MYSQL_DATABASE`
- `QV_API_PORT`
- `QV_API_HOST`
- `QV_DEBUG`

真实凭据放到 `.env` 或 `.env.local`，**不要**把密钥硬编码进仓库。
