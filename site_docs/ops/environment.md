# Environment

## Shared MySQL Variables

- `MYSQL_USER`
- `MYSQL_PASSWORD`
- `MYSQL_HOST`
- `MYSQL_PORT`
- `MYSQL_CHARSET`

## Data Hub Variables

- `TUSHARE_TOKEN`
- `TS_MYSQL_DATABASE`
- `AK_MYSQL_DATABASE`

## Quant Platform Variables

- `QV_MYSQL_DATABASE`
- `QV_API_PORT`
- `QV_API_HOST`
- `QV_DEBUG`

Keep real values in `.env` or `.env.local`. Do not hardcode credentials in the repository.
