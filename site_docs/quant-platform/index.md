# Quant Platform

`quant_platform` 是仓库的量化研究与对外应用项目。

## 职责

- 量化方向的 API 和页面
- 策略流程与回测
- 因子研究与研究资产发布

## 常用命令

启动后端：

```bash
bash apps/quant_platform/scripts/run.sh backend
```

启动前端：

```bash
bash apps/quant_platform/scripts/run.sh frontend
```

初始化本地应用数据：

```bash
bash apps/quant_platform/scripts/run.sh init
```
