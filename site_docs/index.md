# StockProject Docs

StockProject is a Python-first A-share monorepo with two main applications:

- `apps/data_hub`: data ingestion, persistence, scheduling, exploration, and monitoring
- `apps/quant_platform`: research workflows, backtesting, visualization, and application APIs

This portal is the repo-level documentation entrypoint for both:

- developers who need setup, architecture, and operational commands
- research users who need `analysis`, `findings`, and `quant_platform` research entrypoints

## Start Here

- If you are new to the repo, go to [Getting Started](getting-started.md)
- If you work on ingestion and monitoring, go to `Data Hub`
- If you work on research and strategy workflows, go to `Quant Platform`
- If you need environment variables, tests, or run commands, go to `Ops / Dev`

## Main Sections

- `Data Hub`: production data flows, exploration UI, and research-facing `analysis`
- `Quant Platform`: product-facing app plus factor and backtest research
- `Ops / Dev`: shared environment, testing, and common command index
- `Repo Governance`: repo-level boundaries and document placement rules
