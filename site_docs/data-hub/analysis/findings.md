## 高信号做多组合

- `首板涨停 + 主力大幅流入`：胜率高，短窗口收益曲线稳健
- `极低获利比例 + 放量`：样本量大，正向偏置稳定
- `看多因子 >= 7 个亮灯`：触发频率较低，但 conviction 更强

## 高信号回避 / 做空组合

- `跌停 + 主力大幅流出`：当前总结中最强的下跌延续信号
- `机构大幅净卖出`：次日预期为负
- `户数骤增 + 高换手`：拥挤 / 派发风险信号
